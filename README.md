# Todo App Demo

Ứng dụng quản lý công việc đơn giản bằng HTML/CSS/JavaScript thuần — không cần cài đặt thư viện.

## Tính năng
- Thêm / xóa / đánh dấu hoàn thành công việc
- Lọc: Tất cả / Chưa xong / Đã xong
- Tự động lưu vào `localStorage` của trình duyệt

## Chạy thử
Mở file `index.html` bằng trình duyệt, hoặc bật GitHub Pages cho repo này.
